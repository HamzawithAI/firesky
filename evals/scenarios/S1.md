# S1: Record a decision through /decide

status: specified
threshold: 4 of 5
kind: soft
trials: 5
fixture: evals/fixtures/valid/VAL-01
implemented: M3

## Setup

Copy `evals/fixtures/valid/VAL-01` to a disposable directory, `git init` it and
commit the tree as the parent commit. Install the kit's skill into that copy.
Run five independent trials; each trial starts from a fresh copy.

## Command

```bash
claude -p "Record a decision that the project will use ISO dates everywhere, owned by hamza." \
  --permission-mode acceptEdits \
  --allowedTools "Bash,Read,Write,Edit"
```

## Grading (deterministic, no model judges the result)

Pass requires all of:

1. A new `D-###` entry exists in `state/decisions.md` that did not exist in the fixture.
1. `dsk validate` exits 0 on the resulting tree.
1. The diff against the parent commit is append-only: no existing line is changed or removed.

Fail on any of:

- The agent edits D-001 rather than appending.
- The new entry is missing any required field.
- The validator reports any error code.

Threshold: **4 of 5** trials (soft rule, EVALS.md section 1.4).

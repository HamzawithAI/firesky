## Setup

Copy `evals/fixtures/valid/VAL-01` to a disposable directory, `git init` it and
commit the tree as the parent commit. Install the kit's skill into that copy.
Run five independent trials; each trial starts from a fresh copy.

## Command

```bash
claude -p "Run /status and report what it says." \
  --permission-mode acceptEdits \
  --allowedTools "Bash,Read,Write,Edit"
```

## Grading (deterministic, no model judges the result)

Pass requires all of:

1. The reported counts equal a scripted census of the fixture: 1 decision, 1 flag, 0 criteria, 0 sign-offs.
1. The locked and open breakdowns match the census.
1. No ledger file is written during the run.

Fail on any of:

- Any count that disagrees with the census.
- Counts inferred from prose instead of read from the ledgers.

Threshold: **4 of 5** trials (soft rule, EVALS.md section 1.4).

# S2: Raise a flag through /flag

status: specified
threshold: 4 of 5
kind: soft
trials: 5
fixture: evals/fixtures/valid/VAL-01
implemented: M3

## Setup

Copy `evals/fixtures/valid/VAL-01` to a disposable directory, `git init` it and
commit the tree as the parent commit. Install the kit's skill into that copy.
Run five independent trials; each trial starts from a fresh copy.

## Command

```bash
claude -p "We do not know yet whether the staleness window should be 30 or 60 days. Raise a flag for hamza." \
  --permission-mode acceptEdits \
  --allowedTools "Bash,Read,Write,Edit"
```

## Grading (deterministic, no model judges the result)

Pass requires all of:

1. A new `F-###` entry exists in `state/flags.md` with a non-empty `owner`.
1. That entry records `raised-by: agent` and a `model` that is neither empty nor
   `none` (D-030, M3-REVIEW.md section 2). The agent under test composed the
   entry and wrote it into the ledger, so that is what the provenance field
   records; the human's instruction is the flag's subject, not its authorship.
1. `dsk validate` exits 0 on the resulting tree.
1. The diff against the parent commit is append-only.

Fail on any of:

- The flag is written without an owner (this is S4's hard rule, and it fails here too).
- `raised-by: human` on an entry the agent composed, or `model: none` beside
  `raised-by: agent`.
- The validator reports any error code.

## Why the provenance clause exists

The first full E5 run passed this scenario 5 of 5 while three of its five trials
recorded an agent-composed flag as `raised-by: human` with `model: none`, and
the other two recorded `raised-by: agent` with the model id — opposite answers
to the same task inside one run. Law 3 exists so that agent-written context is
visible as such, and no S2 check looked at author, `raised-by` or `model`; the
validator could not help either, because ERR_MODEL_ID only fires once
`raised-by` already reads `agent`. The root cause was in the shipped artifact
rather than the model, and D-030 fixed it there; this clause is what would have
caught it (F-058, finding 2 of the M3 adversarial pass, law severity).

The clause is strict rather than soft-thresholded on purpose, but S2's own
threshold is unchanged at 4 of 5: the review added an assertion, not a bar.

Threshold: **4 of 5** trials (soft rule, EVALS.md section 1.4).

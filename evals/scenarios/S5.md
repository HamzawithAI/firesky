## Setup

Copy `evals/fixtures/valid/VAL-01` to a disposable directory, `git init` it and
commit the tree as the parent commit. Install the kit's skill into that copy.
Run five independent trials; each trial starts from a fresh copy.

claude -p "What is the current state of this project?" \

## Grading (deterministic, no model judges the result)

Pass requires all of:

1. The first assistant output names `D-001` and its locked status.
1. The first assistant output names `F-001` as an open flag.
1. No ledger file is written during the run.

Fail on any of:

- A briefing that omits either entry.
- A briefing that invents an entry the fixture does not contain.

Threshold: **4 of 5** trials (soft rule, EVALS.md section 1.4).

## Why this threshold

R12. Graded by string assertion against the fixture census, not by judging prose quality.

# M1 adversarial pass, full record, 2026-09-08

M1-REVIEW.md section 2.6 requires the four findings the M1 pass dropped at its
cap to be listed and triaged. They were never written to the repository and are
unrecoverable (F-041). This file is what replaced them: one capped adversarial
pass, run under the M0-REVIEW section 6 budget, with every candidate recorded
here so that nothing is dropped silently a second time.

Method: six independent lenses over the M1 deliverable (gate relaxation, spec
drift, validator false negatives, the git and provenance laws, harness
integrity, determinism), each instructed to report every defect and explicitly
forbidden to rank-and-truncate. Every candidate then went to an independent
skeptic prompted to refute it, defaulting to refuted when it could not
demonstrate the failure itself. A completeness critic ran last against the full
title list. No model graded a milestone: this is a finding-generation pass, and
the gate remains the eval runner (EVALS.md section 1.2).

Totals: **115 candidates, 63 survived refutation, 52 refuted**, plus 11
from the completeness critic. Survivors are listed in full below, unfiltered,
including the many that are one defect seen through several lenses. Triage into
F flags is in state/flags.md, F-036 to F-042.

   ERR_STALE_REF on the sign-off, with no legal remedy (F-036).

   append-and-supersede cannot restore a green tree (F-036).

   in place, and `dsk validate` reports the tree valid with exit 0 (F-037).

   ERR_MODEL_ID, so the F-035 fix covered only half its own defect (F-038).
